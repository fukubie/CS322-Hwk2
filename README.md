# CS322 Homework 2

This project is a small multi-page HTML website created for a web design assignment in CS322. The site includes a personal bio page, an introduction page, and a themed page inspired by The Little Prince.

## Visit site

[Link](https://fukubie.github.io/CS322-Hwk2/)

## Project Overview

The website is built using plain HTML and CSS and focuses on:

- Creating a personal landing page
- Using images, layout tables, and simple styling
- Linking multiple pages together
- Building a themed literary page with visual design

## Pages Included

- `index.html` — home page with a profile introduction and navigation link
- `introduction.html` — a page presenting skills, abilities, education, and training
- `little_prince.html` — a stylized page featuring a quote and visual design inspired by The Little Prince

## Folder Structure

- `index.html` — main home page
- `introduction.html` — details page
- `little_prince.html` — literary-themed page
- `img/` — all images and animated GIF assets used across the site
- `README.md` — project documentation

## Notes

This project demonstrates foundational web development skills, including HTML structure, styling with inline CSS, image usage, hyperlinks, and simple page navigation.
